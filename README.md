# Tang Portfolio

A recruiter-facing personal portfolio built with Next.js.

## Local run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Before publishing

Replace these placeholders:
- `your-email@example.com`
- `https://github.com/your-github`
- Add `public/resume.pdf`
- Add screenshots / GIFs / videos to each project detail page
- Edit project titles, metrics and copy in `data/projects.ts`

## Deploy

1. Push this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Deploy with the default Next.js settings.
4. Add a custom domain later if needed.
